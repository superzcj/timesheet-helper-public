安装工时助手

Windows 和 Mac 的 Chrome、Edge、Arc 都可以使用。只需安装一次。

  1. 确保已经解压安装包，并保留整个 timesheet-helper 文件夹。
  2. 在浏览器地址栏输入 chrome://extensions（Edge 可输入 edge://extensions），按回车。
  3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择本页面所在的 timesheet-helper 文件夹。
  4. 打开并登录工时系统，在工时列表或新增页面右下角点击「工时助手」。
助手会先检查已填日期。选择月份后，可点击上班日标记个人休息，核对后再确认提交。

如果扩展没有出现，确认开发者模式保持开启，并刷新工时页面。更新和日期配置说明见同文件夹的 README.md。
