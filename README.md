# 工时填报助手

在工时列表或新增页面快速检查并填报工时。日期由 [workdays.json](workdays.json) 统一维护，工时固定为每天 8 小时。

## 安装

Windows 和 Mac 的 Chrome、Edge 或 Arc 均可使用：

1. 从[最新发布](https://github.com/superzcj/timesheet-helper-public/releases/latest)下载安装包并解压，或直接解压维护者提供的安装包；无需 GitHub 账号。
2. 打开解压后的 `INSTALL.html`，按页面中的三步完成安装。安装只需做一次，解压后的文件夹需要保留。
3. 登录工时系统并刷新页面，在工时列表或新增页面右下角点击「工时助手」。

浏览器会要求打开开发者模式并选择解压后的文件夹；Arc 关闭开发者模式时会停用本地扩展。需要更省事的一键安装和自动更新时，可考虑将扩展提交至浏览器扩展商店，审核和发布需由维护者完成。

## 使用

打开助手后，先选择月份。月历按统一排班标出上班日和休息日；点击上班日可标记个人请假或休息，再次点击可恢复。助手会自动检查当前账号的已填记录，绿色下划线表示该日期已有记录。核对项目和日期后，点击「提交所选」并确认即可；未来日期不会填报。

个人休息日按账号和月份保存在当前浏览器中。带问号的日期尚未包含在统一排班中，不会自动填报；请等待维护者更新工具。

## 更新

- **更新排班或工具**：下载并解压[最新安装包](https://github.com/superzcj/timesheet-helper-public/releases/latest)，在扩展管理页移除旧版并加载新版文件夹。不要同时启用两个版本。
- 如果使用 Git 克隆了仓库，也可以运行 `git pull --ff-only`，在扩展管理页重新加载助手，再刷新工时页面。

排班随安装包提供，不会自动从仓库下载。维护者更新排班后，需要让使用者更新工具。

## 维护日期

编辑 [workdays.json](workdays.json)：保留 `schemaVersion: 1`，更新 `updatedAt` 和 `coverage`，在 `workdays` 中列出覆盖范围内已确认的上班日期，然后提交并发布新版安装包。以下仅展示格式：

```json
{
  "schemaVersion": 1,
  "updatedAt": "2026-11-03",
  "coverage": { "start": "2026-11-01", "end": "2026-11-30" },
  "workdays": ["2026-11-02", "2026-11-03", "2026-11-07"]
}
```

日期可以包含未来日期；覆盖范围最多 366 天，所有上班日期必须在范围内。节假日、调休和大小周均以明确日期为准，工具不会根据周次猜测假期后的安排。已整理的日期依据见 [CALENDAR.md](CALENDAR.md)。维护者也可以直接分发安装包。

## 查重和验证

助手读取当前账号的历史记录，同一天任何项目已有记录就跳过；每次提交前再次查询，提交后回查。查询不完整或结果不明确时会停止，不会自动重试。不同客户端同时提交仍可能存在时间窗口，使用者应核对预览和结果。

扩展仅在配置的工时系统页面运行，使用浏览器现有登录状态，不单独保存系统密码。运行 `node --test tests.test.js` 可验证日期、查重和中断处理；`node fixture-server.js` 提供不连接真实系统的模拟页面。
